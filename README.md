# CoachFit — Fitness Coach Landing Page

A lightweight, responsive landing-page prototype for a fitness coach. Built with HTML, CSS and vanilla JavaScript, without a front-end framework.

## Run locally

```sh
python3 -m http.server 8000
```

Open http://localhost:8000 in your browser.

## What this demonstrates

- Responsive site layout with service and contact sections
- Mobile navigation and lightweight animations
- Straightforward deployment to a static hosting service
